# LCB Website (Production)

The production website for LinkedIn Community Bangladesh, deployed at [linkedincommunitybangladesh.com](https://linkedincommunitybangladesh.com).

> **The actual application lives in [`lcb-website/`](./lcb-website)** — see that folder's README for the full design philosophy, tech stack, and setup instructions. This repo also contains `DEPLOY.md`, `HARDENING_CHECKLIST.md`, `SECURITY_REPORT.md`, `PRIORITY_FIXES.md`, and `PHOTOS.md` alongside it, all inside `lcb-website/`.

## Quick Start

```bash
cd lcb-website
npm install
npm run dev
```

## Security

A full security audit has already been performed — see [`lcb-website/SECURITY_REPORT.md`](./lcb-website/SECURITY_REPORT.md) for findings and fixes applied (critical admin-auth-bypass and stored-XSS issues were found and resolved).
